MY MESSENGER — STARTER PROTOTYPE

How to run:
1. Extract my_messenger_starter.zip.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Click a contact and send a message. Demo messages are saved in your browser's local storage.

What works:
- Responsive messenger-style UI for desktop and mobile
- Sample contacts and conversations
- Search chats
- Send messages inside the demo
- Local browser saving

Important:
This is a front-end prototype, not yet a real online messenger. Messages are only stored in the current browser; they do not reach other people. Real accounts, cross-device chat, server/database, secure authentication, push notifications, photo upload, and real audio/video calling need backend services.

Easy customization:
- App name: search for "My Messenger" in index.html
- Colors: edit --primary and --primary2 in the CSS :root section
- Sample contacts: edit starterContacts in the JavaScript section
- Your profile display name: edit "Tushar Murmu" in index.html
